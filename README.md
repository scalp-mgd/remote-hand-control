# Remote Hand Control

Управление компьютером жестами рук через веб-камеру с голосовым вводом текста. Система распознает жесты в реальном времени, перемещает курсор, выполняет клики, скроллинг и позволяет диктовать текст с автоматической расшифровкой речи (STT).

## Возможности

| Жест | Действие | Описание |
|------|----------|----------|
| Открытая ладонь | Движение курсора | Trackpad-стиль: относительное перемещение, как на тачпаде ноутбука |
| Быстрый щипок (большой + указательный, < 0.3 сек) | Клик | Быстро сжать и отпустить — левый клик мыши |
| Долгий щипок (> 0.3 сек) + движение руки | Скролл | Удерживать щипок и двигать руку вверх/вниз для прокрутки |
| Кулак | Enter | Нажатие клавиши Enter (отправка сообщения) |
| Палец вверх (удержание) | Запись голоса | STT через Groq Whisper large-v3-turbo — после отпускания пальца текст вставляется через ~1 сек |

**Голосовой ввод:** пока палец поднят, идет запись с микрофона. После смены жеста или потери руки аудио целиком отправляется в Groq Whisper large-v3-turbo (cloud API). Через ~0.5–1.5 сек распознанный текст с правильной пунктуацией и заглавными буквами вставляется в активное окно через буфер обмена (`Ctrl+V` / `Cmd+V`). Whisper отлично понимает сленг, имена собственные, технические термины и смешанную русско-английскую речь.

## Стек технологий

- **MediaPipe Hands** (Tasks API) — детекция 21 ключевой точки руки
- **MLP Gesture Classifier** (PyTorch -> ONNX -> onnxruntime) — классификация жестов по ключевым точкам
- **PyAutoGUI** — управление курсором и клавиатурой
- **sounddevice** — захват аудио с микрофона
- **Groq Whisper large-v3-turbo** — cloud STT, бесплатный tier, ~1 сек латенси, топ качество русского с пунктуацией
- **OpenCV** — захват видео с камеры и HUD-оверлей
- **pyperclip** + системные хоткеи — вставка кириллического текста через буфер обмена (Win32 API на Windows, `Cmd+V` через pyautogui на macOS, `Ctrl+V` через pyautogui на Linux)
- **PyYAML** — конфигурация

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Получите Groq API ключ (для голосового ввода)

Голосовой ввод работает через Groq Whisper large-v3-turbo — бесплатный tier 30 запросов/мин, что более чем достаточно.

1. Зайдите на https://console.groq.com (логин через Google)
2. Settings → API Keys → Create API Key
3. Скопируйте ключ (начинается с `gsk_...`)
4. Создайте файл `.env` в корне проекта (можно скопировать `.env.example`):
   ```
   GROQ_API_KEY=gsk_ваш_ключ_здесь
   ```

Файл `.env` в `.gitignore` — на git не попадёт.

### 3. Скачайте модели

```bash
python setup_models.py
```

Это скачает MediaPipe Hand Landmarker (~12 МБ). Vosk больше не нужен — STT теперь облачный.

### 4. Обучение классификатора жестов (если нет готовой модели)

См. раздел [Обучение жестов](#обучение-жестов) ниже.

### 5. Запуск

```bash
python main.py
```

Для выхода нажмите `q` в окне камеры.

## Обучение жестов

Классификатор жестов обучается на ваших собственных данных. Это двухэтапный процесс:

### Шаг 1: Сбор данных

```bash
python training/collect_data.py
```

- Покажите руку перед камерой
- Нажмите цифровую клавишу (0-3) для сохранения текущего жеста:
  - `0` — open_palm (открытая ладонь)
  - `1` — fist (кулак)
  - `2` — one_finger_up (палец вверх)
  - `3` — other (другое)
- Рекомендуется собрать 200+ сэмплов каждого класса
- Данные сохраняются в `models/keypoints.csv`

### Шаг 2: Обучение

```bash
pip install -r requirements-train.txt
python training/train_classifier.py
```

- Архитектура: MLP (42 -> 64 -> 32 -> num_classes) с Dropout
- Обучение 200 эпох с валидацией (80/20 split)
- Результат: `models/gesture_classifier.onnx`
- Финальная верификация через onnxruntime

## Архитектура

### Машина состояний

Система работает в трех состояниях:

```
         open_palm              one_finger_up
IDLE ─────────────► TRACKING   IDLE/TRACKING ──────────► RECORDING
 ▲                      │                                     │
 │    hand lost /       │                                     │
 │    grace timeout     │                     gesture change /│
 └──────────────────────┘                     hand lost       │
                                              ────────────────┘
                                                     │
                                                     ▼
                                                   IDLE
```

- **IDLE** — ожидание. Рука не управляет курсором.
- **TRACKING** — открытая ладонь обнаружена, курсор следует за движением руки. В этом состоянии работают клик (щипок), скролл (долгий щипок) и Enter (кулак). При потере руки — grace period (15 кадров) перед возвратом в IDLE.
- **RECORDING** — палец поднят, идет запись голоса с real-time STT. Остановка при смене жеста или потере руки (с задержкой 1.5 сек).

### Потоки

- **Главный поток:** захват кадра -> MediaPipe -> классификация -> state machine -> HUD -> отображение
- **Аудио-поток (sounddevice callback):** складывает аудио-чанки в буфер
- **Транскрипция (daemon thread):** при остановке записи — отправка буфера в Groq, ожидание ответа (~1 сек), вставка текста

### Обнаружение щипка (Pinch Detection)

Щипок определяется по евклидову расстоянию между кончиком большого пальца (landmark 4) и кончиком указательного (landmark 8). Порог настраивается через `actions.pinch_threshold`. Не требует обучения классификатора.

- **Быстрый щипок (< 0.3 сек):** клик при отпускании
- **Долгий щипок (>= 0.3 сек):** переход в режим скролла, дельта Y руки -> прокрутка

## HUD-оверлей

Окно камеры отображает:

- **Скелет руки** — 21 ключевая точка и соединения (зеленые линии, красная точка на указательном пальце)
- **FPS** — частота кадров (верхний левый угол)
- **Состояние** — IDLE / TRACKING / RECORDING (под FPS)
- **Жест + уверенность** — например "open_palm (95%)" (верхний правый угол)
- **Индикатор записи** — красная точка + "REC" (верхний центр) при записи голоса
- **Счетчик слов** — "Hearing N words..." под индикатором записи
- **Текущее действие** — CLICK / ENTER / MOVE / SCROLL / REC START / REC STOP (нижний центр, цветное, исчезает через 1 сек)

## Известные ограничения

- **Кириллица в OpenCV** — `cv2.putText` не поддерживает кириллицу, поэтому HUD отображает текст латиницей (названия жестов, состояния).
- **Нужен интернет для голосового ввода** — Groq STT работает через cloud. Если интернета нет — голосовой ввод недоступен. Жесты и курсор продолжат работать.
- **Одна рука** — по умолчанию трекинг одной руки (`max_hands: 1`).
- **Освещение** — качество детекции зависит от освещения и положения камеры.

## Платформы

Приложение кросс-платформенное: **Windows**, **macOS**, **Linux**.

Разработано и основательно протестировано на:
- **ОС:** Windows 10

- **CPU:** AMD Ryzen 5 4600H

### Установка на macOS

1. **Разрешения Accessibility** (обязательно):
   `System Settings → Privacy & Security → Accessibility` — добавь туда Terminal (или iTerm / VS Code / что ты используешь для запуска `python main.py`). Без этого pyautogui не сможет кликать и печатать.

2. **Разрешение на камеру и микрофон**: при первом запуске macOS попросит, нажми «Allow».

3. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```
   На Mac `pyautogui` автоматически подтянет `pyobjc` для управления мышью/клавиатурой.

4. **Запуск:**
   ```bash
   python main.py
   ```
   (`run.bat` — это Windows-скрипт, на маке он не нужен.)

### Установка на Linux

Нужны системные пакеты для pyautogui:
```bash
sudo apt install python3-tk python3-dev scrot
pip install -r requirements.txt
python main.py
```

### Системные требования

- **Камера:** любая USB-камера или встроенная веб-камера
- **Микрофон:** для голосового ввода
